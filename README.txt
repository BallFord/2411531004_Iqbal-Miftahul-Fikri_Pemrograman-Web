DESKRIPSI PROYEK
----------------
Website ini adalah portofolio pribadi yang dirancang untuk memenuhi Ujian Akhir Semester (UAS) mata kuliah Desain Web. Website ini menampilkan profil lengkap, riwayat pendidikan, keahlian, serta galeri aktivitas saya di bidang Musik, E-Sport, Otomotif, dan Organisasi Kampus.

STRUKTUR FILE
-------------
1. index.html       : Halaman utama (Home) yang berisi Hero Section, Ringkasan Minat & Keahlian, dan Highlight Galeri.
2. about.html       : Halaman profil (About) berisi Visi Misi, Riwayat Pendidikan, Organisasi, dan Skills.
3. portofolio.html  : Halaman galeri karya dengan fitur Filter Kategori (Tabs) dan Detail Pop-up (Modal).
4. kontak.html      : Halaman kontak berisi Informasi Alamat (Maps) dan Formulir Pesan dengan Validasi.
5. css/custom.css   : File CSS kustom untuk styling tambahan (Background, Warna, Transparansi).
6. images/          : Folder yang berisi gambar

FITUR 
-------------
- Framework         : Bootstrap 5.3.0 (CDN)
- Styling           : Custom CSS 
- Components        : 
  > Navbar 
  > Grid System 
  > Carousel 
  > Accordion 
  > Modal 
  > Navs & Tabs 
  > Form Validation 
  > Google Maps Embed
- Icons             : FontAwesome 6 (CDN)

CATATAN TAMBAHAN
----------------
- Website menggunakan background gambar Universitas Andalas dengan efek parallax.
- Formulir kontak memiliki validasi input dan akan memunculkan notifikasi sukses jika valid.
- Galeri Portofolio memiliki fitur filter kategori: Music, E-Sport, Automotive, dan Campus.
